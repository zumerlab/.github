# ZumerLab

**Embracing the unconventional.**

Open-source tools for the web: DOM capture, visual tools for coding agents, and interfaces that move in circles and zoom instead of scrolling. Everything is MIT.

[zumerlab.com](https://zumerlab.com) · [Sponsor](https://github.com/sponsors/tinchox5)

</div>

## Capture

| | | |
|---|---|---|
| **[SnapDOM](https://github.com/zumerlab/snapdom)** | A high-performance DOM engine that captures a rendered element in the browser and exports it as PNG, SVG or canvas. Plugins add PDF, HTML, vector, GIF, video, live streaming and context for agents. Zero dependencies. | ![stars](https://img.shields.io/github/stars/zumerlab/snapdom?style=flat&label=★&color=2d5bff) ![npm](https://img.shields.io/npm/dm/@zumer/snapdom?style=flat&label=npm&color=2d5bff) |
| **[SnapDIFF](https://github.com/zumerlab/snapdiff)** | Visual regression for components, in the browser. Capture a baseline, change the code, see what moved. | ![stars](https://img.shields.io/github/stars/zumerlab/snapdiff?style=flat&label=★&color=2d5bff) |
| **[SnapEye](https://github.com/zumerlab/snapeye)** | Capture, compare and record for coding agents. One command, a PNG, a diff or a GIF in a folder the agent can read. | ![stars](https://img.shields.io/github/stars/zumerlab/snapeye?style=flat&label=★&color=2d5bff) |
| **[SnapSurf](https://github.com/zumerlab/snapsurf)** | Web navigation and verification for AI agents: reach a state, check that it happened. MCP server included. | ![stars](https://img.shields.io/github/stars/zumerlab/snapsurf?style=flat&label=★&color=2d5bff) |

## Interfaces

| | | |
|---|---|---|
| **[Orbit](https://github.com/zumerlab/orbit)** | A CSS framework for radial UI: dials, gauges, menus, progress rings and whatever else fits on a circle. | ![stars](https://img.shields.io/github/stars/zumerlab/orbit?style=flat&label=★&color=2d5bff) |
| **[Orbit Kit](https://github.com/zumerlab/orbit-kit)** | Declarative web components built on Orbit: gauges, charts and instruments you drop into a page. | ![stars](https://img.shields.io/github/stars/zumerlab/orbit-kit?style=flat&label=★&color=2d5bff) |
| **[Zumly](https://github.com/zumerlab/zumly)** | Zoom-based navigation for any site, with plain HTML. Pages become a space you move through instead of a stack you flip. | ![stars](https://img.shields.io/github/stars/zumerlab/zumly?style=flat&label=★&color=2d5bff) |

## How we work

Small libraries, no runtime dependencies when we can help it, framework-agnostic, and shipped often: SnapDOM alone has had about one release a week for the past year. If something breaks, open an issue; if something is missing, a PR is welcome.

Made by [Juan Martín](https://github.com/tinchox5) and contributors.
